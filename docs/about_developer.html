App Evolution

The Journey — How This App Evolved

From Python scripts on a D: drive to a production-grade offline desktop application — the full story.

01
Phase 1 — The Seed Python Question Generator
May – Aug 2025
D:\Documents\cnc-phase-1

The idea was simple but powerful: algorithmically generate infinite unique CNC problems so that no two students ever get the same exercise. Using Python and Jupyter notebooks, I built generators for 6 geometry types — hemispheres, circles, rectangles, toroids, ellipses, and parabolas — producing randomized coordinate sets, technical drawings, and Moodle XML question banks.

"Why can't we just generate the exercises? Every student gets a unique problem. No copying. No memorization. Pure understanding."
Python 3.8 Jupyter Notebook NumPy Matplotlib ezdxf (DXF/CAD) Moodle XML
10+ Notebooks
6 Geometry Types
40+ Output Files
∞ Unique Problems
"But the questions had no home — they needed a delivery platform with security and tracking."
02
Phase 2 — The Platform Docker + Moodle + Tauri Secure Browser
Oct 2025 – Jan 2026
C:\cnc-moodle-tauri

The generated questions needed a secure delivery channel. I deployed a full Docker-based Moodle LMS with Traefik reverse proxy, MariaDB, and Redis caching. To prevent answer-sharing, I built a custom Tauri 2 desktop application as a locked-down secure browser with Ed25519 cryptographic device authentication.

"Students can share answers via WhatsApp in seconds. We need cryptographic locking — signed devices, signed sessions, no screenshots."
Docker Compose Traefik v2.11 Moodle LMS MariaDB 11.2 Redis 7.2 Tauri 2.0 Rust Ed25519 Crypto PowerShell
3 Components
17 Security Fixes
5 Docker Services
Ed25519 Device Auth
"Too complex for ITI deployment — Docker, servers, internet required. Needed something that works on one click, zero infra."
03
Phase 3 — The Product CNC Interactive Learning
Feb 2026 – Present Live · v0.1.9
C:\cnc-vue-tauri → interactive-glass-schematic

Strip away all server dependencies. One installer. One app. Works on any Windows PC without internet. The current platform is a fully standalone, offline-first desktop application with encrypted SQLite storage (AES-256-GCM), HMAC-SHA256 score signing, a Monaco-powered G-Code editor, interactive SVG schematics, an intelligent recommendation engine, admin dashboard, and the infinite practice system — all in one binary.

"One installer. One app. No Docker. No server. No internet. Just works. This is what ITI needs."
