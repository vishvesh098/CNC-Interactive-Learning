App Evolution

The Journey — How This App Came to Life

From a simple idea on a laptop to a full desktop application used in classrooms — the story in three stages.

01
Phase 1 — The Idea Generate Unlimited Practice Problems
May – Aug 2025

Why should every student practise the same question? The idea was powerful in its simplicity: automatically generate a unique CNC exercise for every student, so no two people ever see the same problem. This eliminates copying and forces genuine understanding. I wrote programs that create randomized coordinate sets, technical drawings, and question banks covering six different geometry shapes.

“Every student gets a unique problem. No copying. No memorisation. Pure understanding.”
Python 3.8 Jupyter Notebook NumPy Matplotlib ezdxf (DXF/CAD) Moodle XML
10+ Programs
6 Geometry Types
40+ Output Files
∞ Unique Problems
Technical details
Geometry types: hemispheres, circles, rectangles, toroids, ellipses, parabolas. Output formats: DXF technical drawings, coordinate data files, Moodle XML question banks. Toolpaths generated via parametric equations with trigonometric and Pythagorean approaches.
“The questions had no home — they needed a secure delivery platform where answers couldn’t be shared.”
02
Phase 2 — The Platform Secure Online Exam System
Oct 2025 – Jan 2026

The generated questions needed to reach students securely. I built a locked-down exam application that only runs on registered computers — no screenshots, no copying answers, no sharing via messaging apps. This was paired with an online question bank system to manage and distribute the content.

“Students share answers in seconds. We needed a system where you can only open the exam on an authorised machine — and nothing else.”
Tauri 2.0 Rust Docker Compose Online LMS Cryptographic Auth PowerShell
3 Components
17 Security Fixes
5 Services
Signed Device Auth
Technical details
Docker Compose with Traefik v2.11 reverse proxy, Moodle LMS, MariaDB 11.2, Redis 7.2 caching. Tauri 2 secure browser with Ed25519 cryptographic device authentication, screen-capture blocking, and signed sessions.
“Too complex for ITI — servers and internet aren’t always available. Needed something that works on a single click, no infrastructure.”
03
Phase 3 — The App CNC Interactive Learning — One Installer, Everything Included
Feb 2026 – Present Live · v0.1.14

One installer. One application. Activate once, then the classroom runs offline. Everything the previous phases built now lives in a single desktop app — interactive CNC schematics, a two-phase G-Code workspace with weighted scoring and a Monaco editor, rich lessons, encrypted student records, searchable attempt history with locked review, a question bank with a recommendation engine, a scientific calculator, guided onboarding tours, issue reporting, a live survey analytics dashboard, and the infinite unique-problem system. Licences are activated and devices enrolled once; content and app updates then arrive signed, from the Microsoft Store and the content delivery worker. Nothing to run on site, nothing for the student to configure.

“One installer. Nothing to run on site. The classroom works offline. This is what an ITI needs.”

Technical details
Frontend: Vue 3 + Pinia 3 + Vite 7 + TypeScript + Monaco Editor + GSAP + TipTap. Backend: Rust via Tauri 2, AES-256-GCM encrypted SQLite, HMAC-SHA256 score signing, Ed25519-signed content verified on device. Delivery: MSIX from the Microsoft Store; encrypted content and update policy fetched from a Cloudflare Worker. Testing: Vitest across components, stores and end-to-end flows. 6.5K lines of Rust and 52K+ lines of frontend code across 136 source files (tests and build output excluded).

How Was This Built? AI as a Force Multiplier

That three-stage journey was accomplished not by a software engineer, but by a mechanical engineer using AI coding agents. By pairing deep domain knowledge of CNC manufacturing with state-of-the-art AI tools, the entire application was designed, architected, and validated — from interactive schematic viewers to encrypted score storage, from G-Code editors to the recommendation engine. AI didn't replace expertise; it amplified it. 59,000+ lines of production-ready code shipped by a single domain-expert builder.
