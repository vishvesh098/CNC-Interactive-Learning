# Scientific Calculator

The built-in scientific calculator provides quick access to mathematical operations without leaving the application. It supports standard arithmetic, trigonometric functions, angle mode toggling, memory operations, and calculation history.

---

## Opening the Calculator

The calculator is accessible from the **Global Sidebar** on the left side of the screen:

1. Click the **Calculator icon** in the sidebar
2. The calculator panel opens in the side panel area
3. Click the icon again to close the calculator

---

## Calculator Display

The calculator display shows:

- **Current expression** — The formula you are typing
- **Live preview** — The calculated result appears in real-time as you type
- **Angle mode indicator** — Shows `DEG` or `RAD` in the corner
- **Copy button** — Click to copy the current result to clipboard

---

## Standard Operations

| Button | Function | Example |
|---|---|---|
| `0`–`9` | Number input | Type `42` |
| `.` | Decimal point | Type `3.14` |
| `+` | Addition | `5 + 3 = 8` |
| `-` | Subtraction | `10 - 4 = 6` |
| `×` | Multiplication | `6 × 7 = 42` |
| `÷` | Division | `20 ÷ 4 = 5` |
| `=` | Evaluate expression | Press to finalize |
| `C` | Clear all | Resets the display |
| `⌫` | Backspace | Deletes last character |

## Scientific Operations

### Trigonometric Functions

| Button | Function | Notes |
|---|---|---|
| `sin` | Sine | Uses current angle mode (DEG/RAD) |
| `cos` | Cosine | Uses current angle mode (DEG/RAD) |
| `tan` | Tangent | Uses current angle mode (DEG/RAD) |
| `sin⁻¹` | Arc sine | Press `2nd` first to access |
| `cos⁻¹` | Arc cosine | Press `2nd` first to access |
| `tan⁻¹` | Arc tangent | Press `2nd` first to access |

| Button | Function | Example |

| `xʸ` | Power | `2ʸ³ = 8` |
| `√x` | Square root | `√9 = 3` |
| `³√x` | Cube root | `³√27 = 3` |

## Angle Mode: DEG vs RAD

The calculator supports two angle modes for trigonometric functions:

| Mode | Description | When to Use |
|---|---|---|
| **DEG** | Degrees (0-360) | Most CNC machining calculations |
| **RAD** | Radians (0-2π) | Advanced mathematical work |

**To switch modes:** Click the `DEG`/`RAD` indicator in the display area. The mode toggles between the two settings.

---

## Memory Operations

The calculator provides standard memory functions:

| Button | Function | Description |
|---|---|---|
| `MC` | Memory Clear | Clears the stored memory value |
| `MR` | Memory Recall | Displays the stored memory value |
| `M+` | Memory Add | Adds the current result to memory |
| `M-` | Memory Subtract | Subtracts the current result from memory |

---

## 2nd Function Mode

Press the **`2nd`** button to access inverse and alternate functions:

- `sin` → `sin⁻¹` (arc sine)
- `cos` → `cos⁻¹` (arc cosine)
- `tan` → `tan⁻¹` (arc tangent)
- `√x` → `³√x` (cube root)
- `x²` → `x³` (cube)

The `2nd` button highlights when active. Press it again to return to standard functions.

---

## Calculation History

The calculator maintains a history of your recent calculations.

### Viewing History

1. Click the **History icon** in the calculator side panel header
2. The panel switches from keypad view to history view
3. Each entry shows the expression, result, and timestamp

### Recalling a Calculation

- Click any entry in the history list to recall the result into the current expression
- This allows you to build on previous calculations without re-typing

### History Persistence

- History is preserved across calculator open/close cycles
- History is cleared when you log out of the application

## Using the Calculator During Activities

The calculator is available during any activity:

- **CNC Practice Activities** — Calculate coordinates, feed rates, or spindle speeds
- **Schematic Activities** — Quick measurements or conversions
- **Text Lessons** — Work through example problems

The calculator runs independently and does not interfere with your activity progress or auto-save.
