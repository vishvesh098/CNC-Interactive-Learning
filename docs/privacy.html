Privacy Policy

Last Updated: June 2, 2026

This Privacy Policy describes how CNC Interactive Learning (the "Application") collects, uses, protects, and handles user data. The Application is a desktop platform designed for classroom, lab, and independent study to teach CNC programming concepts.

1. Hosting & Offline Operation

The Application is designed primarily as an offline-first desktop application. It runs locally on your Windows machine and does not require an active internet connection to function, evaluate coordinate points, validate G-Code, or record training attempts.

2. Information Collection and Use

A. Locally Stored Data (On-Device)

All training progress, scores, and configurations are stored directly on the host device within an encrypted SQLite database. This includes:

  • User Profile Info: Sign-in credentials, student usernames, and role types (Student/Admin).
  • Progress & Chapter Stats: Completion percentages, chapter readiness scores, and unlocked chapter states.
  • Attempt History: Snapshots of entered coordinates, submitted G-Code lines, scores achieved, attempt durations, and timestamps.

B. Administrator-Configured Network Sync

If configured by your institution or administrator, the Application may connect to an external cloud database (such as Supabase). When enabled, this integration is used exclusively for:

  • Synchronizing chapter progression and test scores to an instructor dashboard.
  • Reviewing diagnostics and issue reports submitted by students.

C. Issue & Diagnostic Reports

If you encounter an issue during a training activity (e.g., coordinate mismatches or G-Code validation errors) and choose to submit a report, the Application gathers the following information to assist administrators in updating the question bank:

  • The Unique Question Code (qcode).
  • The selected Issue Type (e.g., SVG Issue, G-Code Issue).
  • Any custom text description you type in the report window.

3. Data Security and Integrity

We take the security of student academic data seriously:

  • Encryption at Rest: Local databases are encrypted using AES-256-GCM encryption. Cryptographic keys are managed securely on the local device via integration with the Windows Credential Manager / OS Keyring.
  • Cryptographic Verification: All submitted test scores are cryptographically signed using an HMAC-SHA256 signature generated by the secure Rust backend. This ensures scores cannot be tampered with or modified via client-side storage edits.
  • Content Protection: The correct answers for G-Code questions are compiled into the secure backend binary and are never exposed as plain text to the application frontend.

4. Third-Party Services

When downloaded through the Microsoft Store, Microsoft may collect telemetry, crash dumps, and download statistics associated with your Microsoft account. Please refer to the Microsoft Privacy Statement for details.

5. Children's Privacy

The Application is designed for educational environments. It does not actively solicit or collect personally identifiable information from children. All student profiles and scores are managed locally or within an private database hosted and controlled by the educational institution.

6. Changes to this Policy

We may update this Privacy Policy from time to time to reflect changes in security standards or application features. The "Last Updated" date at the top of the policy indicates when revisions were made.

7. Contact Information

For questions regarding this Privacy Policy or data security within the Application, please contact the developer or your institution's system administrator.
